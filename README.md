# Color Changer 🎨

My first JavaScript project!

## What it does
- Click the **Red, Blue, Green or Yellow** buttons to change the background color of the page
- The **title color** changes to black when a color is selected
- The **Reset button** color also changes to match the theme
- Click **Reset** to go back to the original dark background

## Buttons
- Red — changes background to red
- Blue — changes background to blue
- Green — changes background to green
- Yellow — changes background to yellow
- Reset — brings everything back to default

- HTML structure and tags
- CSS styling, variables and flexbox
- JavaScript event listeners
- How to manipulate page styles using JS
